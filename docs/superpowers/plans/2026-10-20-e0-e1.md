# E0 and E1 implementation plan

**Goal:** Freeze reproducible, provenance-linked audiovisual inputs and start a bounded MuseTalk 1.5 offline experiment.

**Architecture:** A small standalone experiment repository. Standard-library scripts prepare/validate private media and tracked manifests; pinned upstream MuseTalk runs in an independent environment. No browser renderer or online speech integration in this round.

**Spec:** Approved voice_ai Avatar guide, E0 and E1. Source: `/path/to/projects/voice_ai/reports/Avatar 口型生成 技术路线 实验指南.md`.

**Constraints:** No subagents, staging, commits, remotes or pushes. Never stop/restart existing services. Generated media private by default. Record failures and timing boundaries. The new empty repository is its own isolated workspace; a Git worktree cannot exist before an initial commit and is unnecessary here.
